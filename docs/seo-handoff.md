## Launch checklist

- [ ] One canonical domain
- [ ] HTTPS everywhere
- [ ] Redirect old URLs (pennypaytech.com WordPress pages)
- [ ] Update sitemap
- [ ] Keep robots.txt clean
- [ ] Avoid accidental noindex
- [ ] Use unique titles
- [ ] Use unique meta descriptions
- [ ] Use proper heading hierarchy
- [ ] Compress images and video
- [ ] Prevent layout shift
- [ ] Serve crawlable HTML content
- [ ] Validate structured data
- [ ] Track Search Console and Bing
- [ ] Monitor click-through rate and impressions
